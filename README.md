# HazeBusting_Website

Website for **Haze-Busting Global Services** (HR services, Hadapsar, Pune) — static HTML, CSS and JavaScript.

## Versions

| Version | Where | What it is |
|---|---|---|
| **v0.1** | tag `v0.1` | First premium build (dark blue theme, real logo, Call Now, redesigned Contact) |
| **v0.3** | tag `v0.3` | Current theme: charcoal + bronze gold on ivory, logo blue/grey accents, flip cards, animated HR Services — **dark photo hero (city towers)** |
| **v0.4** | tag `v0.4` | Same as v0.3 with a **bright team photo + brand-blue hero** on Home |
| **v0.5** | tag `v0.5` (branch `release/v0.5`) | **Brighter design** per client feedback: brand-blue replaces the dark charcoal, light blue wash on heroes, bright people photos, white industries ticker, light "Why" section |
| **v0.6** | tag `v0.6` (branch `release/v0.6`) | **Fresh & bright redesign**: white and sky-tint backgrounds, light navigation with the logo on a brand-blue tile, light hero with the photo on the right, logo-blue primary colour with sunny amber call-to-action buttons, no dark bands |
| **v0.7** | tag `v0.7` (branch `release/v0.7`) | v0.6 design with the company name changed to **Haze-Busting Global Services** (new logo lettering, page titles, footer and metadata) |
| **v0.14** | tag `v0.14` (branch `release/v0.14`) | Colour option — **Midnight Indigo & Coral**: Midnight indigo with coral accents. Same design, content and animations as v0.7 |

`v0.2` is the working branch that led to v0.3. Check out any version with `git checkout v0.3`, `v0.4` or `v0.5`.

## Run
Open `index.html` in a browser. Pages are generated from `tools/build.js` (`node tools/build.js`); styles in `css/style.css`, behaviour in `js/main.js`.
